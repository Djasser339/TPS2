# Smart Farm Management System

A Java project built for an Object-Oriented Programming (OOP) course. It simulates a smart farm management system with both a **console interface** and a **JavaFX graphical interface**.

## What it does

The app lets you manage a farm split into different zones:

- **Crop zones** — track cereals, vegetables, and fruits with growth stages and soil conditions
- **Livestock zones** — manage cattle and poultry with health records and feeding programs
- **Aquaculture zones** — monitor fish with water quality sensors

On top of that, the system handles:

- **Sensors** — environmental (temperature, humidity), soil (pH, nitrogen), water, biometric, and GPS sensors
- **Alerts** — automatic warnings when sensor readings go out of range (warning / critical levels)
- **Commercial management** — clients and sales tracking
- **Dashboard** — charts and statistics overview of the whole farm

## Tech stack

- Java (JDK 17+)
- JavaFX — for the graphical interface
- OOP design patterns — Singleton, State, Factory, and Inheritance hierarchies

## How to run

1. Clone the repository
2. Open in IntelliJ IDEA (recommended)
3. Make sure JavaFX is configured in your SDK/libraries
4. Run `Smart_Farm/SmartFarmApp.java` for the GUI version
5. Or run `Main.java` for the console menu version
